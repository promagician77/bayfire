# First Pass Approval

One static page, no build step, no dependencies.

A fire sprinkler design walkthrough prepared for a contractor.

1. **Standard** - 13 / 13R / 13D decision tool, including the mixed-use case
2. **Rejections** - what actually gets a submittal sent back, and the prevention
3. **Package** - the complete submittal checklist
4. **Turnaround** - realistic timelines, and where the calendar goes
5. **Pricing** - fixed per project, hourly where it fits better

All code references must be confirmed against the locally adopted edition and
the jurisdiction's amendments. No NFPA table values are reproduced here.

## Run

```bash
npm run dev      # http://localhost:3000
```
